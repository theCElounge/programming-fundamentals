Lab 001 / 014 Lab 1 of 14

Lab Blink & Loop

Your first steps into embedded programming. Learn to install Thonny IDE, connect the Arduino Nano 33 BLE Sense Rev2, and write a MicroPython program that blinks an LED — the "Hello World" of hardware.

Learning Objectives

By the end of this lab, you will be able to:

  1. Install and configure Thonny IDE on your computer.
  2. Connect the Arduino Nano 33 BLE Sense Rev2 to your computer.
  3. Write a MicroPython script that blinks an LED.
  4. Use variables to control program behavior.
  5. Understand the while True infinite loop — the backbone of embedded programs.

Lab Information

Hardware
Arduino Nano 33 BLE Sense Rev2
Duration
60–90 minutes
Prerequisites
None — this is your first lab!
IDE
Thonny (recommended)

Part 1: Installing Thonny IDE

Thonny is a beginner-friendly Python IDE designed for learning. It works great with MicroPython boards and requires no complex setup.

Step 1: Download Thonny

  1. Open your web browser and go to thonny.org (opens in a new window).
  2. Click the Download button.
  3. Select the version for your operating system:
    • Windows: Download the .exe installer (e.g., thonny-4.1.7.exe).
    • macOS: Download the .dmg file.
    • Linux: Use your package manager or download the .AppImage.

Step 2: Install Thonny

On Windows

  1. Double-click the downloaded .exe file.
  2. Click Yes if prompted by User Account Control.
  3. In the installation wizard, click Next through each screen.
  4. You can leave the default installation options as they are.
  5. Click Install and wait for the process to complete.
  6. Click Finish.

On macOS

  1. Open the downloaded .dmg file.
  2. Drag the Thonny icon into the Applications folder.
  3. Open Applications and double-click Thonny.
  4. If macOS warns about an unidentified developer, go to System Settings > Privacy & Security and click Open Anyway.

Step 3: Launch Thonny

  • Windows: Search for "Thonny" in the Start Menu and click it.
  • macOS: Open the Applications folder and double-click Thonny.

You should see a window with the editor area at the top and the shell area at the bottom.

Part 2: Connecting Your Arduino Nano 33 BLE Sense

Step 1: Identify the Board

Your Arduino Nano 33 BLE Sense Rev2 has the following components:

  • A small RGB LED (red, green, blue) near the center.
  • A micro-USB port on one end.
  • A reset button (labeled "RST").
  • Several pins along the sides for connecting sensors.

Step 2: Connect via USB

  1. Take the micro-USB cable and plug the small end into the Arduino board.
  2. Plug the USB-A end into an available USB port on your computer.
  3. You should see a small green power LED light up on the board. This means the board is receiving power.
💡 Tip: Use a data-capable USB cable (not just a charging cable). If the computer doesn't recognize the board, try a different cable or USB port.

Step 3: Install MicroPython Firmware on the Board

Out of the box, the Nano 33 BLE Sense runs Arduino firmware — it does not come with MicroPython pre-installed. Before Thonny can talk to the board, you must flash the MicroPython firmware. You only need to do this once per board.

  1. Go to the Arduino MicroPython Installer (opens in a new window) page and download the installer for your operating system.
  2. Open the installer while your board is connected via USB.
  3. Quickly double-tap the RST button on the board to put it into bootloader mode (the onboard LED will begin pulsing slowly).
  4. In the installer, select your board (Arduino Nano 33 BLE Sense Rev2) and click Install MicroPython.
  5. Wait for the installation to finish, then close the installer.
💡 Note: If the installer doesn't detect your board, double-tap the RST button again. Flashing MicroPython replaces any Arduino sketch on the board — you can always restore Arduino support later by re-uploading a sketch from the Arduino IDE.

Step 4: Select the MicroPython Interpreter in Thonny

  1. In Thonny, go to Tools > Options (on macOS: Thonny > Settings).
  2. Click the Interpreter tab.
  3. Select MicroPython (generic) from the interpreter list.
  4. In the Port dropdown, select the port that corresponds to your Arduino board:
    • Windows: It will look like COM3, COM4, etc. (You may see multiple COM ports — try each one if unsure).
    • macOS: It will look like /dev/cu.usbmodem... or /dev/cu.wchusbserial....
  5. Click OK.

Step 5: Verify the Connection

  1. After clicking OK, the shell should display a MicroPython welcome banner and a >>> prompt. If it doesn't, click the Stop/Restart backend button (red stop icon) in the toolbar, or press Ctrl+F2.
  2. In the shell at the bottom, type the following and press Enter:
Python — Verify Connection 
print("Hello, World!")

You should see this output in the shell:

Shell Output 
>>> print("Hello, World!")
Hello, World!
>>>

If you see Hello, World!, congratulations! Your board is connected and ready to go.

🔧 Troubleshooting:
  • Nothing happens when you press F5? Make sure you selected the correct interpreter and port in Tools > Options.
  • You see an error like OSError: [Errno 5] EIO? The board may not be properly connected. Try a different USB port or cable.
  • You see multiple COM ports? Unplug the Arduino, note which COM port disappears, then plug it back in. That's your board's port.

Part 3: Your First MicroPython Program — Blinking the LED

Understanding the Hardware

The Arduino Nano 33 BLE Sense has a built-in LED connected to Pin 13. This is the same LED used in every beginner's embedded programming journey. On this board:

  • Setting Pin 13 to 1 turns the LED ON.
  • Setting Pin 13 to 0 turns the LED OFF.
💡 Note on pin numbering: In MicroPython on this board, machine.Pin(13) refers to the nRF52840 microcontroller's pin P0.13 — which is where the built-in orange LED is connected. It conveniently matches the "D13" label used in Arduino sketches, but the two numbering schemes are not the same thing in general.

Step 1: Write the Code

Click in the editor area (the top white space) and type the following code exactly as shown:

Python — lab1_blink.py 
import machine
import time

# Create a variable for the LED on Pin 13
led = machine.Pin(13, machine.Pin.OUT)

print("Starting blink program...")

while True:
    led.value(1)        # Turn LED ON
    time.sleep(1)       # Wait 1 second
    led.value(0)        # Turn LED OFF
    time.sleep(1)       # Wait 1 second

Step 2: Save Your File

  1. Click File > Save (or press Ctrl+S on Windows / Cmd+S on macOS).
  2. Choose where to save the file. A good location is your Desktop or a new folder called ProgrammingFundamentals.
  3. Name the file lab1_blink.py.
  4. Click Save.
💡 Why save as .py? The .py extension tells Thonny (and your computer) that this is a Python file.

Step 3: Run the Program

  1. Make sure your cursor is in the editor (click somewhere in the code area).
  2. Click the green Run button (▶) in the toolbar, or press F5.
  3. Watch the small LED on your Arduino board!

What should happen: The LED should blink on and off, once per second, forever.

Expected Output 
>>> Starting blink program...
[LED blinks on, waits 1 second, blinks off, waits 1 second, repeats...]

Step 4: Stop the Program

If you want to stop the blinking:

  • Click the Stop button (■, a red square) in the toolbar, or press Ctrl+C in the shell.

Part 4: Understanding the Code

Let's break down every line of the program:

Python — Annotated 
import machine          # Line 1: Import the hardware control library
import time             # Line 2: Import the time library for delays

led = machine.Pin(13, machine.Pin.OUT)  # Line 4: Configure Pin 13 as an output

print("Starting blink program...")  # Line 6: Print a message to the shell

while True:              # Line 8: Start an infinite loop
    led.value(1)         # Line 9: Set Pin 13 to HIGH (LED ON)
    time.sleep(1)        # Line 10: Pause for 1 second
    led.value(0)         # Line 11: Set Pin 13 to LOW (LED OFF)
    time.sleep(1)        # Line 12: Pause for 1 second

Key Concepts Explained

Concept What It Does Why It Matters
import machine Gives us access to control pins, PWM, sensors, etc. Without this, we can't talk to the hardware.
import time Gives us sleep(), ticks_ms(), and other timing functions. We need delays so the LED doesn't blink too fast to see.
machine.Pin(13, machine.Pin.OUT) Tells the board: "Pin 13 will send signals out." Pins can be inputs (reading sensors) or outputs (controlling LEDs, motors).
led.value(1) Sends a HIGH signal (3.3 volts) to Pin 13. This turns the LED on.
led.value(0) Sends a LOW signal (0 volts) to Pin 13. This turns the LED off.
time.sleep(1) Pauses the program for 1 second. Without this, the LED would blink so fast it would look like it's always on.
while True: Creates a loop that never ends. Embedded programs (like blinking LEDs) need to keep running forever.

MicroPython Pin Reference

Pin Number Function on Nano 33 BLE Sense
13 Built-in orange LED (pin is shared with the SPI clock, SCK)
0–12 General-purpose digital I/O (some shared with sensors)
A0–A7 Analog input pins
SDA I2C data line
SCL I2C clock line
GND Ground (0 volts)
3.3V Power output (3.3 volts)
5V Power output (5 volts from USB) — disconnected by default; requires soldering the VUSB jumper pads on the back of the board

Useful MicroPython Functions

Function What It Does Example
machine.Pin(pin, mode) Create a pin object led = machine.Pin(13, machine.Pin.OUT)
pin.value(val) Set or get pin state led.value(1)
time.sleep(seconds) Pause for given seconds time.sleep(0.5)
time.sleep_ms(ms) Pause for given milliseconds time.sleep_ms(500)
print(text) Display text in the shell print("LED is on")
