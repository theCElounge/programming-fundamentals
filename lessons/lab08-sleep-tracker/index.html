Lab Sleep Tracker

Read rotational motion from the BMI270 gyroscope, use the time module to timestamp movement events, and summarize a session into a sleep-quality estimate.

Learning Objectives

By the end of this lab, you will be able to:

  1. Read rotational motion from the onboard BMI270 gyroscope.
  2. Use the time module to timestamp events over a long-running session.
  3. Build an event log that records movement rather than every single reading.
  4. Summarize a session into a simple sleep-quality estimate.
  5. Practice relative timestamps versus absolute clock time.

Part 1: Meet the Gyroscope

So far, you've used the BMI270's accelerometer half. Its other half is a gyroscope, which measures rotational speed — how fast the board is spinning around each axis, in degrees per second (°/s). Unlike the accelerometer, the gyroscope reads near zero whenever the board is still, no matter its orientation, which makes it a great motion detector for something like overnight movement tracking.

Python — gyro_test.py 
import machine
from bmi270 import BMI270

i2c = machine.I2C(1)
imu = BMI270(i2c)

# .read_gyro() returns (x, y, z) in degrees per second
gx, gy, gz = imu.read_gyro()
print(f"gx={gx:.1f} gy={gy:.1f} gz={gz:.1f} (deg/s)")

Leave the board still: all three values should hover near 0.0. Rotate it slowly in your hand and watch the relevant axis climb.

Part 2: The Time Module for Long-Running Sessions

You've used time.sleep() since Lab 1, but tracking sleep needs more: we need to know when each movement happened relative to when the session started. MicroPython's time module gives us a running millisecond counter for exactly this purpose.

FunctionWhat it does
time.ticks_ms()Milliseconds since the board booted (wraps around eventually — always use ticks_diff to compare).
time.ticks_diff(new, old)Safely computes elapsed milliseconds between two ticks_ms() readings.
Python — Shell 
>>> import time
>>> start = time.ticks_ms()
>>> time.sleep(2)
>>> elapsed_ms = time.ticks_diff(time.ticks_ms(), start)
>>> elapsed_ms
2003
>>> elapsed_minutes = elapsed_ms / 1000 / 60
>>> round(elapsed_minutes, 2)
0.03
💡 Why not a real clock? Most MicroPython boards don't keep accurate wall-clock time without extra setup (like syncing over the network). For this lab, we track time relative to when the session starts, which is all a sleep tracker actually needs.

Part 3: Logging Movement Events, Not Every Reading

If we logged every single gyroscope reading all night, the file would be enormous and mostly useless (a sleeping person is still nearly all the time). Instead, we only log an event when the rotational speed crosses a threshold — the same thresholding idea from Labs 6 and 7, applied to a new sensor.

Python — sleep_tracker.py 
import machine
import math
import time
from bmi270 import BMI270

i2c = machine.I2C(1)
imu = BMI270(i2c)

MOVEMENT_THRESHOLD = 15.0   # deg/s -- tune based on testing
SESSION_MINUTES = 1          # shortened for in-class testing; use 480 (8 hrs) for a real run

session_start = time.ticks_ms()
movement_events = []

print(f"Sleep tracking started for {SESSION_MINUTES} minute(s)...")

while True:
    elapsed_ms = time.ticks_diff(time.ticks_ms(), session_start)
    elapsed_minutes = elapsed_ms / 1000 / 60

    if elapsed_minutes >= SESSION_MINUTES:
        break

    gx, gy, gz = imu.read_gyro()
    rotation_speed = math.sqrt(gx**2 + gy**2 + gz**2)

    if rotation_speed > MOVEMENT_THRESHOLD:
        event = {
            "minute": round(elapsed_minutes, 2),
            "rotation_speed": round(rotation_speed, 1),
        }
        movement_events.append(event)
        print(f"Movement at minute {event['minute']}: {event['rotation_speed']} deg/s")

    time.sleep(0.2)

print(f"Session complete. {len(movement_events)} movement events logged.")

Part 4: Summarizing the Session

Raw event logs are hard to interpret at a glance. Let's write a summary that turns the list of events into a simple, human-readable estimate.

Python — sleep_summary.py 
def summarize(movement_events, session_minutes):
    event_count = len(movement_events)

    if event_count == 0:
        return "No movement detected -- excellent, restful session."
    elif event_count <= 3:
        return f"Light movement -- {event_count} events. Good quality sleep."
    elif event_count <= 8:
        return f"Moderate movement -- {event_count} events. Fairly restless."
    else:
        return f"Frequent movement -- {event_count} events. Poor quality sleep."

print(summarize(movement_events, SESSION_MINUTES))

# Also write the full log to a file, as in Lab 4
with open("sleep_log.csv", "w") as log_file:
    log_file.write("minute,rotation_speed_deg_per_s\n")
    for event in movement_events:
        log_file.write(f"{event['minute']},{event['rotation_speed']}\n")

print("Full event log saved to sleep_log.csv")
💡 Design choice: The exact cutoffs in summarize() (3 events, 8 events) are a judgment call, not a scientific formula. Real sleep trackers use much more sophisticated models — this is a simplified version to practice the underlying programming ideas: thresholding, event logging, and summarizing data.
