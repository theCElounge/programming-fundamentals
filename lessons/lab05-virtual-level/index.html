Lab The Virtual Level

Read 3-axis accelerometer data from the BMI270, use the math module to calculate real angles, and build a live bubble-level readout.

Learning Objectives

By the end of this lab, you will be able to:

  1. Read 3-axis acceleration data from the onboard BMI270 sensor.
  2. Use Python's math module to compute angles from raw acceleration.
  3. Understand how gravity on each axis reveals the board's tilt.
  4. Map raw sensor values onto a simple coordinate system.
  5. Build a live "bubble level" readout in the shell.

Part 1: Meet the BMI270

The BMI270 is a 6-axis Inertial Measurement Unit (IMU) — it combines an accelerometer (which senses acceleration, including gravity) and a gyroscope (which senses rotation speed) in one chip. This lab uses only the accelerometer half; you'll meet the gyroscope starting in Lab 8.

💡 Sensor driver: Copy the course-provided bmi270.py driver onto your board with Thonny (same process as Labs 3 and 4). You'll reuse this same driver through Lab 9.
Python — accel_test.py 
import machine
from bmi270 import BMI270

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
imu = BMI270(i2c)

# .read_accel() returns a tuple of 3 floats, in units of g (9.8 m/s^2)
x, y, z = imu.read_accel()
print(f"x={x:.2f} g   y={y:.2f} g   z={z:.2f} g")

Lay the board flat on the table and run this. You should see roughly x=0.00, y=0.00, z=1.00 — gravity is pulling straight down the board's Z axis.

Part 2: How Gravity Reveals Tilt

The accelerometer can't directly measure "tilt" — it measures acceleration along three axes. But because gravity always pulls straight down at 1 g, the way that 1 g splits across the X, Y, and Z axes tells us exactly how the board is oriented.

Try tilting the board while it's running the loop below and watch the numbers change:

Python — watch_tilt.py 
import machine
import time
from bmi270 import BMI270

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
imu = BMI270(i2c)

while True:
    x, y, z = imu.read_accel()
    print(f"x={x:+.2f}  y={y:+.2f}  z={z:+.2f}")
    time.sleep(0.2)

Flat on the table: z is near +1.00, x and y are near 0.00. Tilt the board's left edge up: x becomes negative. Tilt the right edge up: x becomes positive. Tilting front/back does the same to y.

Part 3: The Math Module — Turning Gravity into Degrees

Raw g-values like 0.34 aren't intuitive. What we really want is an angle, in degrees. That's where the math module comes in — specifically the atan2() function, which converts two axis readings into an angle.

Python — Shell 
>>> import math
>>> math.pi
3.141592653589793
>>> math.sqrt(16)
4.0
>>> math.atan2(1, 1)      # radians
0.7853981633974483
>>> math.degrees(math.atan2(1, 1))
45.0
💡 Note: On the board you may see fewer decimal places than shown here (e.g. 3.141593 instead of 3.141592653589793). MicroPython on this board uses single-precision floats, while desktop Python uses double precision. The math still works the same — the numbers are just stored with less precision.
💡 Radians vs. degrees: Python's trig functions work in radians, not degrees. Always wrap the result in math.degrees() to get a number you can read naturally.

To find the board's roll (tilt left/right) and pitch (tilt front/back), we compare each horizontal axis against gravity's vertical (Z) component:

Python — virtual_level.py 
import machine
import math
import time
from bmi270 import BMI270

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
imu = BMI270(i2c)

while True:
    x, y, z = imu.read_accel()

    roll = math.degrees(math.atan2(x, z))
    pitch = math.degrees(math.atan2(y, z))

    print(f"Roll: {roll:+6.1f} deg   Pitch: {pitch:+6.1f} deg")
    time.sleep(0.2)

Lay the board flat: both readings should hover near 0.0. Prop up one edge about 45 degrees and watch the corresponding value approach 45.0.

Part 4: A Text-Based Bubble Level

Let's turn the roll angle into a visual indicator, the same way a real bubble level shows a bubble drifting off-center.

Python — bubble_level.py 
import machine
import math
import time
from bmi270 import BMI270

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
imu = BMI270(i2c)

WIDTH = 21  # characters wide, must be odd so there's a true center

while True:
    x, y, z = imu.read_accel()
    roll = math.degrees(math.atan2(x, z))

    # Map roll (-45..+45 degrees) onto a bubble position (0..WIDTH-1)
    clamped = max(-45, min(45, roll))
    position = int((clamped + 45) / 90 * (WIDTH - 1))

    track = ["-"] * WIDTH
    track[WIDTH // 2] = "|"      # center mark
    track[position] = "O"        # the "bubble"

    print("".join(track) + f"   roll={roll:+.1f} deg")
    time.sleep(0.15)

Appendix — Quick Reference

BMI270 Driver Reference (Accelerometer)

MethodReturns
BMI270(i2c)Creates an IMU object on the given I2C bus. Use machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14)) for the internal bus.
imu.read_accel()Tuple (x, y, z) in units of g.

Useful Math Module Functions

FunctionWhat it does
math.sqrt(x)Square root of x.
math.atan2(y, x)Angle (radians) of the point (x, y) from the origin.

math.radians(d)Converts degrees d to radians.
