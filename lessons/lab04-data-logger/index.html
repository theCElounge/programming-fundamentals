Lab 004 / 014 Lab 4 of 14

Lab Data Logger

Read the onboard LPS22HB barometer, organize readings with lists and dictionaries, and write a permanent log file to the board's flash storage.

Learning Objectives

By the end of this lab, you will be able to:

  1. Read barometric pressure and temperature from the onboard LPS22HB sensor.
  2. Store a series of readings using a Python list.
  3. Label each reading with a dictionary.
  4. Write sensor data to a file on the board's flash storage.
  5. Read the log file back and print its contents.

Lab Information

Hardware
LPS22HB Barometric Pressure Sensor (onboard, I2C)
Duration
60–90 minutes
Prerequisites
Lab 3: Weather Reporter
Key Concepts
Lists, dictionaries, file writing

Part 1: Meet the LPS22HB Sensor

The LPS22HB is the onboard barometer — it measures atmospheric pressure (in hectopascals, hPa) and also reports its own internal temperature. Pressure changes with weather and with altitude, which makes this sensor useful for both weather stations and simple altimeters.

💡 Sensor driver: As in Lab 3, copy the course-provided lps22hb.py driver onto your board with Thonny's File > Save As > MicroPython device before starting.
Python — pressure_test.py 
import machine
from lps22hb import LPS22HB

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
barometer = LPS22HB(i2c)

pressure_hpa = barometer.read_pressure_hpa()
temperature_c = barometer.read_temperature_c()

print("Pressure (hPa):", pressure_hpa)
print("Temperature (C):", temperature_c)

Part 2: Storing Readings in a List

A single reading isn't a log — a log is a history of readings over time. Python's list is the tool for that: an ordered, growable collection of values.

Python — Shell 
>>> readings = []
>>> readings.append(1013.2)
>>> readings.append(1013.5)
>>> readings.append(1012.9)
>>> readings
[1013.2, 1013.5, 1012.9]
>>> len(readings)
3
>>> readings[0]
1013.2
>>> readings[-1]
1012.9

Let's collect ten readings, one every two seconds, into a list:

Python — collect_readings.py 
import machine
import time
from lps22hb import LPS22HB

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
barometer = LPS22HB(i2c)

readings = []

for i in range(10):
    pressure = barometer.read_pressure_hpa()
    readings.append(pressure)
    print(f"Reading {i + 1}: {pressure:.1f} hPa")
    time.sleep(2)

print("All readings:", readings)
print("Average:", sum(readings) / len(readings))
print("Minimum:", min(readings))
print("Maximum:", max(readings))
💡 Handy built-ins: sum(), len(), min(), and max() all work directly on lists of numbers — no loop required.

Part 3: Labeling Data with Dictionaries

A plain list of numbers loses context — what time was each reading taken? A dictionary lets us attach labels (keys) to values, so each reading can carry its own metadata.

Python — Shell 
>>> reading = {"pressure_hpa": 1013.2, "temperature_c": 21.6, "sample": 1}
>>> reading["pressure_hpa"]
1013.2
>>> reading["sample"]
1
>>> reading.keys()
dict_keys(['pressure_hpa', 'temperature_c', 'sample'])
💡 Note: Unlike desktop Python (which keeps keys in the order you added them), MicroPython does not guarantee any particular key order — reading.keys() may list the keys in a different order on your board. Always look values up by key, never by position.

Now let's combine lists and dictionaries: a list of dictionaries, where each dictionary is one labeled reading.

Python — labeled_log.py 
import machine
import time
from lps22hb import LPS22HB

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
barometer = LPS22HB(i2c)

log = []

for i in range(5):
    entry = {
        "sample": i + 1,
        "pressure_hpa": barometer.read_pressure_hpa(),
        "temperature_c": barometer.read_temperature_c(),
    }
    log.append(entry)
    print(entry)
    time.sleep(2)

# Access the third reading's pressure
print("Sample 3 pressure:", log[2]["pressure_hpa"])

Part 4: Writing the Log to a File

Readings stored only in a list disappear the moment your program stops. To keep a permanent record, we write them to a file on the board's flash storage using open().

Python — write_log.py 
import machine
import time
from lps22hb import LPS22HB

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
barometer = LPS22HB(i2c)

# "w" = write mode (creates the file, or erases it if it already exists)
with open("pressure_log.csv", "w") as log_file:
    log_file.write("sample,pressure_hpa,temperature_c\n")

    for i in range(5):
        pressure = barometer.read_pressure_hpa()
        temperature = barometer.read_temperature_c()
        log_file.write(f"{i + 1},{pressure:.2f},{temperature:.2f}\n")
        print(f"Logged sample {i + 1}")
        time.sleep(2)

print("Done. Saved to pressure_log.csv")
ModeMeaning
"w"Write — creates a new file, overwrites if it already exists.
"a"Append — adds to the end of an existing file without erasing it.
"r"Read — opens an existing file to read its contents.
💡 Why with? The with open(...) as log_file: pattern automatically closes the file for you when the block ends — even if an error happens partway through. Always prefer it over calling open()/close() manually.

Reading the Log Back

Python — read_log.py 
with open("pressure_log.csv", "r") as log_file:
    contents = log_file.read()

print(contents)

In Thonny, you can also open View > Files, find pressure_log.csv under the MicroPython device, and double-click it to open it. To copy it to your computer, right-click the file and choose Download.

MethodReturns

barometer.read_pressure_hpa()Float — pressure in hectopascals.
barometer.read_temperature_c()Float — internal die temperature in Celsius.
