Lab Gesture Remote

Detect hand gestures with the APDS9960, branch on them with if/elif/else, and build a state machine so the same gesture can mean different things in different modes.

Learning Objectives

By the end of this lab, you will be able to:

  1. Read hand gestures from the onboard APDS9960 sensor.
  2. Use if/elif/else chains to branch on gesture type.
  3. Understand and implement a state machine to track a "current mode."
  4. Map gestures to different actions depending on the current state.
  5. Build a simple gesture-controlled menu remote.

Part 1: Meet the APDS9960

The APDS9960 is the most versatile onboard sensor you'll use — it can sense gestures (a hand swiping up, down, left, or right above it), proximity (how close an object is), ambient light, and even color. This lab focuses on gesture detection; you'll return to its other modes in Labs 11–13.

💡 Sensor driver: Copy the course-provided apds9960.py driver onto your board with Thonny, the same way you did for the earlier sensors. You'll reuse this driver through Lab 13.
Python — gesture_test.py 
import machine
import time
from apds9960 import APDS9960

i2c = machine.I2C(1)
sensor = APDS9960(i2c)

print("Wave your hand above the sensor (up/down/left/right)...")

while True:
    gesture = sensor.gesture()
    if gesture is not None:
        print("Detected:", gesture)
    time.sleep(0.05)

Swipe your hand a few inches above the sensor in each direction. The .gesture() method returns one of "up", "down", "left", "right", or None if nothing was detected on that check.

Part 2: Branching with if/elif/else

So far you've used single if statements and and/or to combine conditions. When you need to pick one action out of several mutually exclusive options, Python's if/elif/else chain is the right tool — it checks each condition in order and runs only the first one that matches.

Python — gesture_actions.py 
import machine
import time
from apds9960 import APDS9960

i2c = machine.I2C(1)
sensor = APDS9960(i2c)

while True:
    gesture = sensor.gesture()

    if gesture == "up":
        print("Volume up")
    elif gesture == "down":
        print("Volume down")
    elif gesture == "left":
        print("Previous track")
    elif gesture == "right":
        print("Next track")
    elif gesture is not None:
        print("Unrecognized gesture:", gesture)

    time.sleep(0.05)
💡 if vs. elif: If you used separate if statements instead of elif, Python would check every condition every time, even after a match. elif stops checking as soon as one branch matches — both clearer and more efficient here, since a gesture can only be one thing at a time.

Part 3: State Machines — Giving Gestures Context

A real remote doesn't treat every gesture the same way all the time — a "right" swipe might mean "next song" while browsing music, but "next photo" while browsing pictures. This requires the program to remember what mode it's currently in. That's the core idea of a state machine: a program that tracks a "current state" in a variable, and lets that state change how it responds to input.

The pattern in code: one variable holds the current state, and the if/elif chain is nested one level deeper — first check the state, then check the gesture.

Python — gesture_state_machine.py 
import machine
import time
from apds9960 import APDS9960

i2c = machine.I2C(1)
sensor = APDS9960(i2c)

state = "menu"   # possible states: "menu", "music", "photos"

print("State machine remote started. Current state:", state)

while True:
    gesture = sensor.gesture()

    if gesture is not None:

        if state == "menu":
            if gesture == "up":
                state = "music"
                print("Entered Music mode")
            elif gesture == "down":
                state = "photos"
                print("Entered Photos mode")

        elif state == "music":
            if gesture == "left":
                print("Previous track")
            elif gesture == "right":
                print("Next track")
            elif gesture == "down":
                state = "menu"
                print("Back to Menu")

        elif state == "photos":
            if gesture == "left":
                print("Previous photo")
            elif gesture == "right":
                print("Next photo")
            elif gesture == "up":
                state = "menu"
                print("Back to Menu")

    time.sleep(0.05)

photosup→ menu state
