Lab Color Matcher

Read RGB color data from the APDS9960, group values with tuples, and use a list comprehension to match readings to the closest named color.

Learning Objectives

By the end of this lab, you will be able to:

  1. Read red, green, and blue color data from the APDS9960 color sensor.
  2. Group related values together using tuples.
  3. Calculate color distance between two RGB tuples.
  4. Use a list comprehension to find the closest match in a list of named colors.
  5. Build a program that names the color of an object held above the sensor.

Lab Information

APDS9960 Color Sensor (onboard, I2C)

60–90 minutes

Tuples, list comprehensions

Part 1: Reading Color as RGB

The APDS9960 has four light-sensing channels: clear (overall brightness, used in Lab 11), and separate red, green, and blue channels. Reading all three color channels together gives us the color of whatever's reflecting light back into the sensor.

Python — color_test.py 
import machine
import time
from apds9960 import APDS9960

i2c = machine.I2C(1)
sensor = APDS9960(i2c)

while True:
    clear, r, g, b = sensor.color()
    print(f"R={r}  G={g}  B={b}")
    time.sleep(0.3)

Hold something brightly colored (a red marker, a blue sticky note) an inch or two above the sensor. The dominant channel should read noticeably higher than the other two.

Part 2: Grouping Values with Tuples

An RGB color is really one idea made of three numbers that belong together. A tuple is Python's way of grouping a fixed set of related values into a single object. You've already been receiving tuples all along — every sensor reading in this course, like (x, y, z) from the accelerometer, is a tuple!

Python — Shell 
>>> red_color = (255, 0, 0)
>>> red_color[0]
255
>>> len(red_color)
3
>>> name, rgb = ("Red", (255, 0, 0))
>>> name
'Red'
>>> rgb
(255, 0, 0)

Part 3: Measuring Color Distance

To find the closest named color to a sensor reading, we treat each RGB triplet as a point in 3D space and measure the distance between them — the same distance formula you used for acceleration magnitude in Lab 6, just applied to color instead of motion.

distance = √((r₁-r₂)² + (g₁-g₂)² + (b₁-b₂)²)
Python — color_distance.py 
import math

def color_distance(color_a, color_b):
    r1, g1, b1 = color_a
    r2, g2, b2 = color_b
    return math.sqrt((r1 - r2)**2 + (g1 - g2)**2 + (b1 - b2)**2)

print(color_distance((255, 0, 0), (200, 20, 10)))   # a reddish color -- small distance
print(color_distance((255, 0, 0), (0, 0, 255)))     # red vs blue -- large distance

Part 4: Finding the Closest Match with a List Comprehension

A list comprehension builds a new list from an existing one in a single, compact line — instead of writing a full for loop with .append(). It's especially handy when you want to transform every item in a collection the same way.

Python — Shell 
>>> numbers = [1, 2, 3, 4]
>>> squares = [n * n for n in numbers]
>>> squares
[1, 4, 9, 16]

# The same thing without a comprehension:
>>> squares = []
>>> for n in numbers:
...     squares.append(n * n)

Now let's use one to compute the distance from a sensor reading to every named color at once, then pick the smallest:

Python — color_matcher.py 
import machine
import math
import time
from apds9960 import APDS9960

i2c = machine.I2C(1)
sensor = APDS9960(i2c)

NAMED_COLORS = [
    ("Red",     (255, 0, 0)),
    ("Green",   (0, 255, 0)),
    ("Blue",    (0, 0, 255)),
    ("Yellow",  (255, 255, 0)),
    ("Cyan",    (0, 255, 255)),
    ("Magenta", (255, 0, 255)),
    ("White",   (255, 255, 255)),
    ("Black",   (0, 0, 0)),
]

def color_distance(color_a, color_b):
    r1, g1, b1 = color_a
    r2, g2, b2 = color_b
    return math.sqrt((r1 - r2)**2 + (g1 - g2)**2 + (b1 - b2)**2)

def closest_color_name(reading):
    # List comprehension: one (name, distance) pair per named color
    distances = [(name, color_distance(reading, rgb)) for name, rgb in NAMED_COLORS]
    # min() with a key function finds the pair with the smallest distance
    closest_name, closest_distance = min(distances, key=lambda pair: pair[1])
    return closest_name

while True:
    clear, r, g, b = sensor.color()
    name = closest_color_name((r, g, b))
    print(f"Detected: {name}  (R={r} G={g} B={b})")
    time.sleep(0.5)
💡 min() with a key: By default min() compares items directly, which wouldn't work well on (name, distance) pairs. The key=lambda pair: pair[1] tells min() to compare using only the distance (the second item), not the name.
