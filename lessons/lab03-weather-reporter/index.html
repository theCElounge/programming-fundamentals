Lab 003 / 014 Lab 3 of 14

Lab Weather Reporter

Interface with the onboard HS3003 sensor, work with floats, and use f-strings to turn raw sensor numbers into a readable weather report.

Learning Objectives

By the end of this lab, you will be able to:

  1. Read live temperature and humidity data from the onboard HS3003 sensor.
  2. Work with floats — Python's data type for decimal numbers.
  3. Use f-strings to format sensor data into readable text.
  4. Convert between Celsius and Fahrenheit using a function.
  5. Round floating-point numbers for cleaner display.

Part 1: Meet the HS3003 Sensor

The Arduino Nano 33 BLE Sense Rev2 has an onboard HS3003 sensor that measures both temperature and relative humidity at the same time. Unlike the LED you controlled in Labs 1 and 2, the HS3003 talks to the board over a protocol called I2C — a two-wire communication bus that lets many sensors share the same two pins.

You don't need to wire anything for this lab: the HS3003 is built into the board and connected to its internal I2C bus.

💡 Sensor driver: This lab uses a small driver module, hs3003.py, provided by your instructor. Before starting, open it in Thonny and use File > Save As > MicroPython device to copy it onto your board (it only needs to be copied once). If you're unsure whether it's already on your board, open View > Files in Thonny and look for hs3003.py in the device file list.

Part 2: Your First Sensor Reading

Let's take a single reading and print it to the shell.

Python — weather_test.py 
import machine
from hs3003 import HS3003

# The onboard sensors share the internal I2C bus
# (SDA = P0.14, SCL = P0.15 on the Nano 33 BLE Sense)
i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
sensor = HS3003(i2c)

# .read() returns a tuple: (temperature_c, humidity_percent)
temperature_c, humidity_percent = sensor.read()

print("Temperature (C):", temperature_c)
print("Humidity (%):", humidity_percent)

Run the program. You should see two numbers printed — both floats (numbers with a decimal point), like 22.4 and 41.8.

🔧 Troubleshooting:
  • ImportError: no module named 'hs3003' — the driver file hasn't been copied to the board yet. See the note above.
  • Readings look frozen or identical every time? Give the sensor a second to settle after power-up before reading it.

Part 3: Working with Floats

So far, every number you've used has probably been an integer (a whole number like 13 or 0). Temperature and humidity aren't whole numbers — they need floats to represent fractional values like 22.4.

TypeExampleUsed for
int13Pin numbers, counts, whole quantities
float22.4Sensor readings, measurements, anything with fractions

Python automatically converts between the two in most math (this is called type coercion), but you can also convert explicitly with float() and int():

Python — Shell 
>>> float(22)
22.0
>>> int(22.9)
22
>>> round(22.4123, 1)
22.4
⚠️ Watch out: int() doesn't round — it truncates (chops off the decimal). Use round() when you want proper rounding.

Celsius to Fahrenheit

Let's write a function that converts our HS3003 reading to Fahrenheit:

Python — convert.py 
import machine
from hs3003 import HS3003

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
sensor = HS3003(i2c)

def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

temperature_c, humidity_percent = sensor.read()
temperature_f = celsius_to_fahrenheit(temperature_c)

print(round(temperature_f, 1))

Part 4: Formatting Output with F-Strings

Printing raw numbers is fine for testing, but a real weather report should read like a sentence. Python's f-strings let you embed variables directly inside text by prefixing a string with f and wrapping variables in curly braces { }.

Python — weather_report.py 
import machine
import time
from hs3003 import HS3003

i2c = machine.I2C(1, scl=machine.Pin(15), sda=machine.Pin(14))
sensor = HS3003(i2c)

def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

while True:
    temperature_c, humidity_percent = sensor.read()
    temperature_f = celsius_to_fahrenheit(temperature_c)

    report = f"Temp: {temperature_c:.1f} C ({temperature_f:.1f} F) | Humidity: {humidity_percent:.1f}%"
    print(report)

    time.sleep(2)

The :.1f inside the braces is a format spec — it means "show this float with exactly 1 digit after the decimal point." This is much more reliable than round() for display purposes, because it always shows the same number of digits.

Format specMeaningExample
{value:.1f}1 digit after the decimal22.4
{value:.2f}2 digits after the decimal22.43
{value:5.1f}Pad to 5 characters wide 22.4
{value:+.1f}Always show a sign+22.4

F-String Cheat Sheet

Python — Reference 
name = "Board"
temp = 22.4123

f"{name} reads {temp} C"        # "Board reads 22.4123 C"
f"{name} reads {temp:.1f} C"    # "Board reads 22.4 C"
