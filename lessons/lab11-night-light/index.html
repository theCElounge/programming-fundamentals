Lab Night-Light

Combine the APDS9960's light and proximity readings with logical operators, and calibrate the darkness threshold for your own room.

Learning Objectives

By the end of this lab, you will be able to:

  1. Read ambient light and proximity levels from the APDS9960.
  2. Combine two sensor conditions using logical operators (and, or, not).
  3. Perform a simple calibration routine for a room's baseline darkness.
  4. Build an automatic night-light that only turns on when it's dark and someone is near.

Lab Information

Hardware
APDS9960 Light + Proximity Sensor (onboard, I2C)

60–90 minutes

Part 1: Reading Light and Proximity

Beyond gestures, the APDS9960 reports ambient light (how bright the room is) and proximity (how close an object is, roughly 0–255, where higher means closer).

Python — light_proximity_test.py 
import machine
import time
from apds9960 import APDS9960

i2c = machine.I2C(1)
sensor = APDS9960(i2c)

while True:
    clear, r, g, b = sensor.color()   # "clear" channel doubles as ambient light level
    proximity = sensor.proximity()

    print(f"Ambient light: {clear}   Proximity: {proximity}")
    time.sleep(0.3)

Cover the sensor with your hand: proximity should climb toward 255 while clear (light level) drops. Shine a phone flashlight on it: clear should spike.

Part 2: Combining Conditions with Logical Operators

A good night-light needs both conditions to be true at once: it should be dark, and someone should be nearby. Checking only one condition gives the wrong behavior — a light-only check would turn the LED on all night even with nobody around; a proximity-only check would turn it on in broad daylight.

Python — Shell 
>>> is_dark = True
>>> is_near = False
>>> is_dark and is_near
False
>>> is_dark or is_near

>>> not is_dark

Part 3: Calibrating for Your Room

"Dark" is relative — a light threshold that works in a windowless room will be wrong in a sunlit one. Instead of hard-coding a fixed number, we calibrate at startup by sampling the current light level and setting the threshold relative to it.

Python — calibrate_light.py 
import machine
import time
from apds9960 import APDS9960

i2c = machine.I2C(1)
sensor = APDS9960(i2c)

print("Calibrating... keep the room at its normal daytime brightness.")
samples = []
for _ in range(10):
    clear, r, g, b = sensor.color()
    samples.append(clear)
    time.sleep(0.2)

baseline_light = sum(samples) / len(samples)
dark_threshold = baseline_light * 0.4   # "dark" = less than 40% of daytime brightness

print(f"Baseline light: {baseline_light:.0f}")
print(f"Dark threshold set to: {dark_threshold:.0f}")
💡 Tip: This same pattern — collect several samples, average them, use that average to set a threshold — is exactly what you did in Lab 9's spirit-level calibration. It's a technique worth recognizing wherever it appears.

Part 4: Building the Night-Light

Python — night_light.py 
import machine
import time
from apds9960 import APDS9960

i2c = machine.I2C(1)
sensor = APDS9960(i2c)
led = machine.PWM(machine.Pin(11))  # green channel of the onboard RGB LED

PROXIMITY_THRESHOLD = 60

print("Calibrating light baseline...")
samples = [sensor.color()[0] for _ in range(10)]
dark_threshold = (sum(samples) / len(samples)) * 0.4
print(f"Dark threshold: {dark_threshold:.0f}")

print("Night-light running. Ctrl+C to stop.")

while True:
    clear, r, g, b = sensor.color()
    proximity = sensor.proximity()

    is_dark = clear < dark_threshold
    is_near = proximity > PROXIMITY_THRESHOLD

    if is_dark and is_near:
        led.duty_u16(0)       # Active-Low: on
    else:
        led.duty_u16(65535)   # off

    time.sleep(0.2)
🔧 Troubleshooting:
  • LED never turns on? Lower PROXIMITY_THRESHOLD, or raise the 0.4 multiplier in the dark-threshold calculation.
  • LED stays on in daylight? Re-run calibration in the actual bright condition, and lower the multiplier (e.g. to 0.3).
