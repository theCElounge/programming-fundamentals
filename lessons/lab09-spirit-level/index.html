Lab Digital Spirit Level

Combine the BMI270's accelerometer and gyroscope with a complementary filter — your first hands-on introduction to sensor fusion.

Learning Objectives

By the end of this lab, you will be able to:

  1. Combine accelerometer and gyroscope readings from the BMI270 — true 6-axis sensing.
  2. Understand why each sensor alone gives an imperfect angle estimate.
  3. Implement a complementary filter — a simple form of sensor fusion.
  4. Use advanced trigonometry to integrate rotational speed into an angle over time.
  5. Build an accurate, drift-resistant digital spirit level.

Lab Information

Hardware
BMI270 6-Axis IMU — Accelerometer + Gyroscope (onboard, I2C)

90–120 minutes

Part 1: Two Sensors, Two Flaws

In Lab 5, you calculated tilt purely from the accelerometer using atan2(). That works well when the board is still, but it has a real weakness: any sudden movement or vibration adds extra acceleration on top of gravity, throwing the angle off — accelerometer-based tilt is noisy.

You could instead estimate angle purely from the gyroscope, by adding up ("integrating") small rotation amounts over time:

angle_new = angle_old + (rotation_speed × elapsed_time)

This is smooth and immune to vibration — but it has the opposite flaw: tiny measurement errors accumulate every time step, so the estimated angle slowly drifts away from the truth even when the board isn't moving at all.

Accelerometer angleGyroscope angle
Short-termNoisy, jumps aroundVery smooth
Long-termStable, no driftDrifts steadily off-target

Part 2: The Complementary Filter

Each sensor is exactly what the other is missing: the accelerometer is reliable long-term but noisy short-term; the gyroscope is smooth short-term but drifts long-term. A complementary filter blends the two, trusting the gyroscope for quick changes and quietly correcting with the accelerometer over time:

angle = 0.98 × (angle + gyro_rate × dt) + 0.02 × accel_angle

This is a real technique used in drones, robots, and phones — it's a lightweight introduction to the broader field called sensor fusion: combining multiple imperfect sensors into one better estimate.

💡 Reading the formula: The weights 0.98 and 0.02 must add up to 1.0. A higher gyroscope weight (like 0.98) makes the output smoother but slower to correct drift; a lower one makes it noisier but more responsive to the accelerometer's long-term accuracy.

Part 3: Implementing the Digital Spirit Level

Python — spirit_level.py 
import machine
import math
import time
from bmi270 import BMI270

i2c = machine.I2C(1)
imu = BMI270(i2c)

GYRO_WEIGHT = 0.98
ACCEL_WEIGHT = 1 - GYRO_WEIGHT

# Start with an accelerometer-only estimate
x, y, z = imu.read_accel()
angle = math.degrees(math.atan2(x, z))

last_time = time.ticks_ms()

print("Digital spirit level running. Ctrl+C to stop.")

while True:
    x, y, z = imu.read_accel()
    gx, gy, gz = imu.read_gyro()

    now = time.ticks_ms()
    dt = time.ticks_diff(now, last_time) / 1000  # seconds
    last_time = now

    accel_angle = math.degrees(math.atan2(x, z))
    gyro_angle = angle + gy * dt   # integrate rotation speed into an angle

    # Complementary filter: blend the two estimates
    angle = GYRO_WEIGHT * gyro_angle + ACCEL_WEIGHT * accel_angle

    level = "LEVEL" if abs(angle) < 1.0 else f"{angle:+.1f} deg"
    print(level)

    time.sleep(0.05)

Try this side-by-side comparison: run the accelerometer-only code from Lab 5 and this fused version at the same time (or one after another) while gently tapping the table. The accelerometer-only reading will jump noticeably; the fused reading barely moves.

Part 4: Calibrating "Level"

Every physical board has a tiny built-in tilt from manufacturing tolerances — true 0.0 degrees on the sensor might not be exactly level on the table. A real spirit level lets you zero it at a known-flat surface.

Python — spirit_level_calibrated.py 
import machine
import math
import time
from bmi270 import BMI270

i2c = machine.I2C(1)
imu = BMI270(i2c)

def read_accel_angle():
    x, y, z = imu.read_accel()
    return math.degrees(math.atan2(x, z))

# --- Calibration step ---
print("Place the board on a known-flat surface, then press Enter.")
input()

samples = [read_accel_angle() for _ in range(20)]
offset = sum(samples) / len(samples)
print(f"Calibration offset: {offset:.2f} deg")

# --- Main loop, now using the offset ---
angle = read_accel_angle() - offset
last_time = time.ticks_ms()
GYRO_WEIGHT = 0.98

while True:
    x, y, z = imu.read_accel()
    gx, gy, gz = imu.read_gyro()

    now = time.ticks_ms()
    dt = time.ticks_diff(now, last_time) / 1000
    last_time = now

    accel_angle = read_accel_angle() - offset
    gyro_angle = angle + gy * dt
    angle = GYRO_WEIGHT * gyro_angle + (1 - GYRO_WEIGHT) * accel_angle

    print(f"{angle:+.1f} deg")
    time.sleep(0.05)

Appendix — Quick Reference

Complementary Filter Reference

Formula 
angle = W * (angle + gyro_rate * dt) + (1 - W) * accel_angle
# W (gyro weight) is typically 0.90 - 0.98
